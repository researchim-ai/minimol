# Безопасность и приватность

- Персональные геномы в этот репозиторий не входят. Для персональной геномики нужна отдельная правовая оценка; здесь её нет.
- HTTP-сервис пишет в лог идентификатор запроса и путь, не последовательность и не SMILES.
- `trust_remote_code` для Carbon-A и Carbon-X выключен, пока revision не закреплён и код не просмотрен.
- Чекпоинты — локальные файлы. `torch.load` используется только для своих запусков.
- Если задан `MINIMOL_API_TOKEN` или аргумент `--token`, все маршруты кроме `/health` требуют `Authorization: Bearer`.
- Публичный запуск без токена — только локальная отладка.
- Ответ API всегда помечен как research use only и не для клинического применения.
- Неподдерживаемый endpoint, неразборчивый SMILES и слишком длинная последовательность дают отказ, а не выдуманную вероятность.
