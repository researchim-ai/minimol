# Релизный чеклист

Автоматическая проверка `minimol release-check` смотрит, что реестр внутренне согласован и карточка модели содержит отказ от клинического применения.

Она **не** выдаёт коммерческий релиз. Поля `human_legal_review` и `human_science_review` остаются `pending`, а `commercial_release` — false.

Перед любым внешним выпуском веса ещё нужно:

- получить решение APPROVED по каждому источнику, включая teacher и исходные геномы;
- зафиксировать split, включая более жёсткий group/scaffold/species holdout;
- приложить метрики, калибровку, устойчивость, задержку и размер файла на названном железе;
- сравнить с baseline и, если teacher решает ту же задачу, с teacher;
- подписать карточку модели и карточку данных;
- оставить пометку «только для исследований».

Модель не выпускается только из-за красивого числа параметров, если она не лучше сильного baseline по качеству или по измеренной стоимости инференса.
